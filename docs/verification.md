# 第一版验证记录

验证平台：Windows x64，2026-11-03。

## 已通过

- `pnpm build`：TypeScript 类型检查和 Vite 生产构建。
- `pnpm test`：20 项前端测试。14 项覆盖头像身份解析（noreply 直出、单页预热、按用户 ID 去重、限流冷却与旧缓存迁移），6 项覆盖提交关系图的线性历史、双亲合并、分页边界和多父节点合并。
- `cargo test --lib`：5 项 Rust 测试。真实临时仓库覆盖空仓库读取、中文文件名、暂存、首次提交前取消暂存且保留后续修改、创建提交、提交文件详情、创建与切换分支、文本 Diff、已提交仓库取消暂存。
- `cargo clippy --lib -- -D warnings`：通过，无警告。
- `pnpm tauri build --bundles nsis`：生成 Windows x64 安装包。
- 浏览器交互：演示仓库打开、全部暂存、填写摘要并提交、提交后工作目录清空、提交文件 Diff、新建分支后切换。
- 界面设置：中英文切换、深浅主题切换。语言与主题使用本机持久存储。
- 窗口布局：1360 × 850 和 960 × 680；最小桌面尺寸下页面宽度无溢出，详情栏保持可用。
- 浏览器控制台：检查时无警告或错误。
